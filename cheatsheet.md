| **Begriff**                        | **Bedeutung**                                                                                                                                                            |
| ---------------------------------- |:------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Klasse                             | Bauplan für Objekte                                                                                                                                                      |
| Objekt                             | Konkretes Exemplar einer Klasse                                                                                                                                          |
| Instanz                            | Anderes Wort für Objekt                                                                                                                                                  |
| Instanziierung                     | Erzeugen eines Objekts aus einer Klasse                                                                                                                                  |
| Attribut                           | Eigenschaft eines Objekts                                                                                                                                                |
| Klassenattribut                    | Attribut, das der gesamten Klasse gehört und von allen<br> Objekten gemeinsam genutzt wird                                                                               |
| Instanzattribut                    | Attribut, das zu genau einem Objekt gehört<br> ("self.attribut") aber nicht der Klasse selbst                                                                            |
| Funktion                           | Wiederverwendbarer Programmblock                                                                                                                                         |
| Methode                            | Funktion innerhalb einer Klasse                                                                                                                                          |
| Parameter                          | Platzhalter in der Definition einer Funktion oder Methode                                                                                                                |
| Argument                           | Tatsächlich übergebener Wert beim Aufruf                                                                                                                                 |
| Rückgabewert                       | Wert, den eine Funktion oder Methode mit return zurückgibt                                                                                                               |
| self                               | Verweis auf das aktuelle Objekt                                                                                                                                          |
| __init__                           | Methode, die beim Erstellen eines Objekts automatisch<br> ausgeführt wird                                                                                                |
| Konstruktor                        | Initialisiert ein neues Objekt (in Python: __init__)                                                                                                                     |
| Objektzustand                      | Gesamtheit aller Attributwerte eines Objekts                                                                                                                             |
| Sichtbarkeit                       | Legt fest, ob auf Attribute oder Methoden von außen<br> zugegriffen werden soll (öffentlich, geschützt, privat)                                                          |
| Öffentlich<br> (attribut)          | Kann von überall aus verwendet werden                                                                                                                                    |
| Geschützt<br> (_attribut)          | Soll nur innerhalb der Klasse und ihrer Unterklassen<br> verwendet werden (Konvention nur in Python)                                                                     |
| Privat<br> (__attribut)            | Vor versehentlichem äußerem Zugriff geschützt                                                                                                                            |
| Verkapselung                       | Schutz interner Daten eines Objekts durch eine öffentliche<br> Schnittstelle                                                                                             |
| Vererbung                          | Eine Klasse übernimmt Attribute und Methoden einer anderen Klasse                                                                                                        |
| Oberklasse/Basisklasse             | Die Klasse, von der geerbt wird                                                                                                                                          |
| Unterklasse/abgeleitete<br> Klasse | Die Klasse, die von einer anderen Klasse erbt                                                                                                                            |
| Überschreiben                      | Eine Unterklasse implementiert eine geerbte Methode neu                                                                                                                  |
| super()                            | Ermöglicht den Zugriff auf Methoden, Attribute oder den<br> Konstruktor der Oberklasse                                                                                   |
| Polymorphie/Überladung             | Gleiche Methode, unterschiedliches Verhalten je nach Objekt                                                                                                              |
| Komposition                        | Ein Objekt besteht aus anderen Objekten (starke<br> "Hat-ein"-Beziehung)                                                                                                 |
| Aggregation                        | Ein Objekt verwendet andere Objekte, die auch unabhängig<br> existieren können (schwache "Hat-ein"-Beziehung)                                                            |
| Generics                           | Platzhalter für Datentypen                                                                                                                                               |
| Interfaces                         | legt fest, was eine Klasse können muss; definiert einen Vertrag, den implementierende<br> Klassen erfüllen.                                                              |
| Abstrakte<br> Klassen              | gemeinsame Basisklasse für verwandte Klassen; kann bereits Attribute und Methoden<br> enthalten, aber auch abstrakte Methoden ohne Implementierung.                      |
| Assoziation                        | allgemeine Beziehung zwischen zwei Klassen. Objekte kennen<br> oder verwenden sich gegenseitig, können aber unabhängig voneinander<br> existieren.                       |
| Komposition                        | starke „besteht-aus“-Beziehung. Das enthaltene Objekt<br> gehört fest zum übergeordneten Objekt und existiert normalerweise nicht<br> unabhänig davon. unabhängig davon. |
| Annotation                         | Metadaten/Kennzeichnung für Programmelemente, z. B. für<br> Compiler oder Frameworks. @Override als Beispiel                                                             |
| Record                             | kompakte Datenklasse mit automatisch erzeugtem Konstruktor,<br> Zugriffsmethoden, `equals()`, `hashCode()` und `toString()`; Datenkomponenten<br> sind `final`.          |
| HTTP<br> Request                   | Anfrage eines Clients an einen Server über HTTP, z. B. mit<br> `GET`, `POST`, `PUT` oder `DELETE`.                                                                       |
| REST-API                           | Web-Schnittstelle, über die Ressourcen mithilfe von<br> HTTP-Requests angesprochen und Daten ausgetauscht werden.                                                        |
| static                             | Gehört zur Klasse statt zu einem einzelnen Objekt; wird von<br> allen Instanzen gemeinsam verwendet.                                                                     |
| Deklaration                        | Eine Variable wird mit Datentyp und<br> Namen festgelegt.                                                                                                                |
| Initialisierung                    | Einer Variable wird zum ersten Mal ein<br> Wert zugewiesen.                                                                                                              |
| Interpreter                        | Führt Code(interpretiert) während der Laufzeit direkt aus.                                                                                                               |
| Compiler                           | Übersetzt den gesamten Quellcode vor<br> der Ausführung in eine andere Form, z. B.<br> Maschinencode oder Bytecode.                                                      |
| Refactoring                        | Verbesserung der internen Struktur von bestehendem Code,<br> ohne dessen Funktion oder Verhalten zu ändern.                                                              |
| Serialisierung                     | Umwandlung eines Objekts in ein speicher- oder<br> übertragbares Format.                                                                                                 |
| Deserialisierung                   | Umwandlung von gespeicherten Daten zurück in ein Objekt.                                                                                                                 |
| Java Pfad anzeigen                 | Zeigt das aktuelle Arbeitsverzeichnis an:<br> `System.getProperty("user.dir")`                                                                                           |
| Java Pfad anzeigen (alternativ)    | Zeigt das aktuelle Arbeitsverzeichnis mit `Path` an:<br> `Path.of("").toAbsolutePath()`                                                                                  |
